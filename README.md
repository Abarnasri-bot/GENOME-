# 🧬 Predict the Genome Pattern: AI/ML DNA Classifier

**Course:** 26BTB101T & Introduction to Computational Biology  
**Assessment:** Assignment 2 (Term Work)  
**Theme:** Dreamcore Dark Edition  

## Overview
An interactive computational biology web dashboard designed for **Assignment 2**. It extracts nucleotide features (`A`, `T`, `G`, `C` counts, sequence length, and `GC%`), simulates machine learning classification (Decision Tree & k-NN), predicts unknown DNA sequences (`ATGCGCGATC`), answers critical assessment questions, and includes a **Nucleotide Dream Catcher** mini-game.

## How to Deploy on Vercel via GitHub
1. Extract this ZIP file.
2. Upload `index.html` and `README.md` to a public GitHub repository.
3. Import the repository into [Vercel](https://vercel.com) and click **Deploy**.
